# 脱敏与边界

本仓库按允许清单导出项目源码、合成测试、能力档案和选定说明；不包含原机 `runtime/`、`backups/`、`config/local.json`、记忆图凭据、语音密钥、QQ 登录态、微信数据库、聊天记录、表情素材或音频、第三方运行时和模型权重。文件名级扫描结果留在原机，不上传，以免泄露机器目录或其他应用信息。

原实现和文档中的三个已知真实 QQ/群标识统一替换为示例数值；本机配置不上传。`config/settings.example.json` 去除账号和群身份，并关闭自动自主探索、主动主人分享及语音，关闭广泛好友/群默认开关。仓库内历史文档描述的是原时间点的部署，不是对本仓库的当前状态承诺。

语音注册档案保留来源、参考编号和历史选择信息以说明架构；音频本身未打包。其说明提到原素材存在第三方版权与使用限制，不能据此推断获得再分发或商业使用许可。其他依赖和内置 Cytoscape 文件以各自的上游许可为准；未给本项目自动添加开源许可证。

自动扫描降低误提交风险，但不能证明不存在所有隐私或授权问题。运行时日志、测试输出、个人素材以及用户提供的配置都应继续留在仓库外；公开或向其他人分享仓库前应重新人工审核。
