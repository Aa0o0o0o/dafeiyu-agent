# Memory V2.1 实施说明

当前文件是本轮现行说明，取代旧文档中的“群不记忆”“每天最多一次”和热聊跟话描述。正式上线状态看 evidence/memory-v2-deployment.json 与 docs/PROGRESS.md。

## 已实现

- M0保护记忆、M1工作类、M2事件与大意、M3稳定/临时语义、M4表达候选、M5逻辑冷存。confidence、保留强度、事件/有效时间分别保存。读取和使用不强化；真实独立会话证据才能强化，H有上限。
- 事件来源和所有涉及主体经实际QQ事件校验，来源原文7天。机器人复述、带引用或媒体的事件不进入自动长期学习；引用和图片仍可用于当前回答。
- 本人稳定偏好更新生成版本，旧版本保留为历史；“今天”临时意愿到上海次日零点，不覆盖稳定偏好。无法准确确定的旧时间不编造。
- 同scope中文关键词/FTS/主体检索，先做策略/时间/状态筛选，再限60候选、8条结果、估算1600tokens。群与主人私聊隔离。受限图最多2跳、每节点12出边、最多2条纯图补充，默认关闭图传播。
- 每scope拒绝/恢复、纠正/删除/保护/取消保护。删除写入无正文持久注册表并fsync，传播至来源、派生、索引、轨迹和布局；epoch/revision在写入、检索、生成及每条气泡最终发送前再次校验。
- 每日上海03:30后进行幂等维护，最多补跑7天；任务租约和重试持久化，过期租约不能提交。过期清理独立于LLM；抽取30条批次、空闲120秒或等待300秒后进行，聊天优先。
- 本机受认证的只读记忆图：真实节点/边、详情/证据/遗忘曲线、筛选/搜索、布局持久化、最近20条24小时召回轨迹、未来0—180天投影、10秒轮询。布局操作不改记忆语义。
- 迁移前备份、影子迁移、账目/外键/一致性检查、最新删除策略恢复闸门；原自动记忆双写关闭。13个旧数据库快照已获用户明确授权满7天清理，只删已知数据库文件，历史源码保留。

## 明确边界与未验收

本轮使用确定性的原文抽取式事件大意及受约束提取，不启用自由改写的“梦境式”全库重写。较复杂的跨事件归纳、别名歧义和自然纠正可能需要显式记忆编号；不承诺像真人一样理解每种表达。表达候选需3个独立语境，不能靠机器人复述、重复读或同会话刷屏获得强化。

容量达到3000活跃非核心/20000冷存时拒绝继续新增并要求维护/复核，不静默删重要记录；自动优先淘汰策略仍需真实数据评估。承诺任务层仅提供带真实回执的存储接口，不擅自增加提醒/执行权限。

180组合成测试不是180条人工审核标签，也不是模型最终回复质量；20段人工盲评、真实群长期体验和实体手机触控/双指缩放尚待验收。没有为这些指标额外调用付费模型或代用户向QQ发送测试消息。

物理删除指活动表正文/索引可用性清理，不承诺对磁盘空闲页或系统备份做取证级抹除。QQ、供应商历史和系统/用户另存副本不在本地服务删除范围。
