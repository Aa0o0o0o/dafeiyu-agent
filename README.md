# 大肥鱼 · Dafeiyu Agent

这是大肥鱼项目的**脱敏私有源码与架构归档**。主体是连接专用普通 QQ 账号的个人对话代理：NapCatQQ / OneBot v11 接入受限 AstrBot 适配器，结合模型、记忆、多媒体、浏览器和有预算的自主探索。功能与权限以实际运行配置、身份核验和工具回执为准。

> 本仓库不是原机的完整备份，也不是克隆后即能启动的安装包。QQ 登录态、密钥、对话与微信记录、记忆库、表情/语音媒体、模型权重及依赖运行环境均未上传。

## 包含什么

`src/` 保存核心实现，包括会话和 QQ 协议边界、Memory V2、工具与浏览器代理、语音、多媒体、自主探索、微信单会话导入；`tts_service/` 为本地语音服务适配层；`memory_ui/` 是记忆图界面；`tests/` 和 `fixtures/` 是离线测试与合成案例；`prompts/` 是实际使用的人格及记忆提炼提示；`config/` 包含不带个人凭据的能力/版本/依赖清单；`docs/` 包含本次整理的架构说明和部分历史实施资料。

仓库里出现的 `1111111111`、`2222222222`、`3333333333` 是替换原机账号/群号的示例值。部分历史实现把账号写死在源码中：复制配置文件并不能使其在其他账号上直接工作。先阅读恢复说明，逐一核验这些限制和测试。

## 部署概览

1. 准备独立普通 QQ 账号、所需授权和隔离环境；仓库不含 QQ 客户端或已登录状态。
2. 参考 `config/versions.json`、各运行时 manifest 和锁文件取得第三方依赖；查验版本、来源及许可。语音参考音频和模型权重需另行准备。
3. 以 `config/settings.example.json` 为模板在本机创建 `config/settings.json`，使用实际账号及拟授权范围，先检查硬编码示例值；本地通过 `scripts/setup_local.py` 交互配置密钥。示例默认关闭自动自主探索、主动分享和语音功能。
4. 先用合成数据及假模型验证身份校验、会话隔离、撤销和发送回执，再按授权连接真实服务。历史测试报告不代表本次克隆环境通过验收。

原机项目、私人数据与原账号设置没有被此归档修改。有关个人账户和外部服务的能力，不应在缺少对应授权或依赖时视作已可用。
